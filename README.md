# Healthcare Billing Anomaly Detection

A data pipeline and full-stack application that flags unusual hospital billing patterns in CMS Medicare data. 

Instead of relying solely on simple averages, this project groups hospitals into hierarchical peer groups (same procedure, similar region) and calculates how far their markup ratios deviate using robust statistical methods (Median and MAD). It also runs an Isolation Forest as an independent second detector. 

Results can be accessed via a command-line interface (CLI), a RESTful API, or an interactive Streamlit dashboard.

## Tech Stack
* **Data Processing:** [DuckDB](https://duckdb.org/) (for fast, in-memory SQL execution and explicit type-safe parsing)
* **Machine Learning:** [Scikit-learn](https://scikit-learn.org/) (Isolation Forest)
* **Backend API:** [FastAPI](https://fastapi.tiangolo.com/)
* **Frontend Dashboard:** [Streamlit](https://streamlit.io/)
* **CLI:** [Typer](https://typer.tiangolo.com/) & [Rich](https://rich.readthedocs.io/)

## Project Structure
The codebase has been streamlined into four highly focused files:
* `pipeline.py`: The core engine. Handles data ingestion, explicit type casting, hierarchical peer grouping, Z-scoring, and the Isolation Forest model.
* `api.py`: A FastAPI application that loads the pipeline into memory and serves the flagged anomalies and statistics via REST endpoints.
* `dashboard.py`: A Streamlit frontend that connects to the FastAPI backend to visualize the data.
* `cli.py`: A Typer command-line interface for running batch reports directly from the terminal.

## Dataset Setup
Because the full CMS Medicare Provider Charge Data (Inpatient FY2016) is large, it is not included in this repository. 

1. Create a `data/raw/` directory in the root of the project.
2. Download the `cms_inpatient_fy2016.csv` file from the [CMS website](https://www.cms.gov/) or a mirror archive.
3. Place the downloaded CSV inside `data/raw/` so the path resolves to `data/raw/cms_inpatient_fy2016.csv`.

## Usage

### 1. Running the CLI
You can generate a report of the top anomalies directly in your terminal:
```bash
python cli.py report data/raw/cms_inpatient_fy2016.csv
```

### 2. Running the API Backend
Start the FastAPI server on port 8000:
```bash
uvicorn api:app --reload --port 8000
```
Once running, you can view the interactive API documentation at [http://localhost:8000/docs](http://localhost:8000/docs).

### 3. Running the Streamlit Dashboard
With the API running in the background, open a new terminal and start the Streamlit application:
```bash
streamlit run dashboard.py
```
This will automatically open your web browser to [http://localhost:8501](http://localhost:8501) where you can interactively filter and view the detected anomalies.

## Note on "Anomalies"
*There is no ground truth for fraud in this dataset.* Flags generated by this tool indicate statistical unusualness worth human review—**not** a definitive verdict of fraud or wrongdoing.
